# Security policy

## Reporting a vulnerability

Please report privately through GitHub: open this repository's **Security** tab and choose
**Report a vulnerability**. Please don't open a public issue for a security problem.

hold-em is maintained in spare time. Reports get a reply as soon as possible, and confirmed
problems are fixed first.

## Scope

- the mod doing something the README's Security section doesn't list
- the saved game or the table showing data it shouldn't
- security problems in this repository's workflows

## Supported versions

Only the latest version on main, and the version the
[claude-mods-games](https://github.com/IanYHChu/claude-mods-games) marketplace currently pins.
Fixes ship as a new version.
